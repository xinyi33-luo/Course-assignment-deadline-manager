\# 课程作业截止日期管理器



一个用 Python 写的命令行小工具，用来管理课程作业截止日期、跟踪完成情况并统计学习负载。



\## 项目背景



这是计算机技能课程的 GitHub 作业。我选择做一个自己真正会用的小工具：管理课程作业截止日期，避免漏交和拖延。



\## 功能



\- 添加作业：课程名、作业标题、截止日期、预计工时

\- 查看全部作业，按截止日期排序，显示剩余天数

\- 查看未完成作业

\- 标记作业完成

\- 统计：总数、已完成、未完成、逾期、完成率、按课程分布、未完成工时

\- 数据保存在本地 JSON 文件
